## Overview

This project consists of designing a long-term multi-asset ETF portfolio for a private wealth management client under realistic allocation constraints. The analysis combines asset allocation, mean-variance portfolio construction, efficient frontier analysis, and Value at Risk constraints in order to build a diversified proposal across major asset classes.

## Main Methods

- Selection of representative ETFs across major asset classes.
- Monthly return analysis using long historical series.
- Mean-variance portfolio construction under no-short-selling constraints.
- Efficient frontier analysis to illustrate the risk-return trade-off.
- Maximum-return portfolio selection subject to a 1-month 99% VaR limit of 3%.
- Discussion of estimation risk in portfolio construction.
