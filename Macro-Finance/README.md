## Overview

This repository contains my individual Macro Finance project combining theoretical derivations, empirical asset-pricing analysis, and bond-market tests.

## Main Topics

- Time-series analysis: Autoregression techniques, prediction cones, simulations, and long-horizon moments.
- Stock market analysis: efficient frontier, global minimum-variance portfolio, and tangency portfolio.
- Cross-sectional strategy analysis: industry momentum, winner-loser portfolios, turnover, and crash episodes.
- Bond market analysis: Campbell-Shiller style tests of the Expectations Hypothesis.

## Repository Content

- `Macro_Indiv_report.pdf`: final written report.
- `Macro_individual_codes.ipynb`: notebook(s) containing the Python implementation and figures.
- Data files used for the empirical analysis.
