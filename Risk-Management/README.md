## Overview

This project studies dependence structures, downside risk measures, and tail risk across five financial assets: SP500, Nasdaq, Gold, Silver, and Bitcoin. It combines descriptive return analysis, empirical copula visualisation, Value at Risk and Expected Shortfall estimation, and Extreme Value Theory tools based on tail-index estimation and Generalized Pareto Distribution fitting. 

## Main Methods

- Weekly and monthly log-return computation.
- Scatter plots and empirical copula analysis for selected asset pairs.
- Empirical and parametric VaR and Expected Shortfall.
- Tail-index estimation using log-log regression on weekly losses.
- GPD estimation using the mean excess property.
- GPD estimation by Maximum Likelihood for tail risk measurement.
