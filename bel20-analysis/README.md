# BEL20 Analysis
- **School:** Louvain School of Management (LSM), Belgium.
- **Programme:** Master in Financial Engineering
- **Course:** Technological Project - Operation research
- **Professor:** Mathieu Van Vyve
- **Year:** 2025-2026 (M1)
- **Author:** Nicolas Poncin

## Description

Academic project applying Markowitz portfolio theory to BEL20 constituents over the 2024–2025 period.

The analysis covers return estimation, covariance analysis, efficient-frontier construction, minimum-variance and tangent portfolios, with and without short-selling constraints.

## Main Methods

- Portfolio return and risk estimation
- Covariance matrix computation
- Mean-variance optimisation
- Efficient-frontier construction
- Long-only portfolio optimisation
