## Overview

This repository contains a notebook from my first experience using Python for finance. 
I completed this project as part of an online training programme, which served as my introduction to financial analysis and basic quantitative workflows before attending the BSE Summer University. 

The instructions were provided in Markdown cells within the notebook, and the objective was to write Python code capable of reproducing the requested outputs.

## Content

- Introductory notebooks on portfolio analysis, Sharpe ratio, portfolio optimisation, and CAPM.
- Small practice exercises used to build familiarity with Python in a finance context. 

## Note

This repository is intentionally modest. It is more a learning archive than a polished project, but it marks the starting point of my Python work in finance.
